# VR Story & Embodied Workshops — Projects we steward (Fall/Winter 2026)

Immersive Story Club's catalog of the VR works we steward, with key art, trailers, laurels, press, artist quotes and curator & practitioner notes.

## Publish on GitHub Pages
1. Create a new repository and upload everything in this folder (keep the `art/` folder next to `index.html`).
2. In the repo, go to **Settings → Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, then save.
3. Your site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

## Editing
- All project text lives in the `<script id="films">` block near the bottom of `index.html` (one entry per work).
- Key art: drop a 16:9 image into `art/` named after the project's `id` (e.g. `art/honeyboys.jpg`) and add that id to the list near `const ART=` in the script.
- Fonts (Gloock, Work Sans) load from Google Fonts.
